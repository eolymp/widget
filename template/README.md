# Widget

The answer surface of an Eolymp widget problem. The question itself lives in the problem statement.

    npx @eolymp/widget dev .     # run it in a local host that behaves like Eolymp
    npx @eolymp/widget pack .    # check it and zip it for upload

`widget.js` is the widget. `lib/` holds the SDK; don't edit it. See AGENTS.md for the full guide.
